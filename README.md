# Japan — 17–27 October 2026

Интерактивный гид по поездке: карта, маршрут по дням, погода, бронирования
и Ghibli-иллюстрации мест. Одна самодостаточная HTML-страница.

**Живая версия:** https://<username>.github.io/<repo>/

## Что внутри

`index.html` — 2,6 МБ, один файл, никаких внешних запросов:

- **Leaflet 1.9.4 + Leaflet.markercluster 1.5.3** — вшиты в страницу, не с CDN
- **Векторная карта Японии** — упрощённый TopoJSON (world-atlas), рисуется без тайлов
- **Названия городов** — 24 подписи, появляются по зуму
- **51 точка / 68 посещений** — кластеризация на общем плане, разбор при зуме,
  spiderfy для точек с одинаковыми координатами
- **20 иллюстраций** — `data:image/webp;base64` прямо в HTML, 768×768, ~79 КБ каждая,
  в двух разных регистрах:
  - **17 стилизованных** под Ghibli — жёлтая обводка на метке, подпись «Ghibli-версия места»
  - **3 документальных** — мемориальный парк, Атомный купол и музей в Хиросиме. Это
    мемориал, а не достопримечательность, поэтому там сдержанное документальное фото,
    подпись «Документальный вид места», без обводки и без игровых заданий

  Провенанс каждой картинки (модель, параметры, точный промпт, id генерации и ссылка
  на исходный PNG) лежит в `img_prompts.json`, там же оба шаблона промптов и заготовки
  на 31 точку без иллюстраций
- **Погода** — климатические нормы на 17–27 окт для 5 городов зашиты в файл
- **Бронирования** — 13 позиций с датами, когда открывается запись
- **Google Maps** — ссылки на место и на маршрут (transit) из каждой карточки
- **Два вида карточки места** — кнопка «◧ Панель» в верхней строке переключает:
  попап на карте (по умолчанию) или боковая панель. В панели до 900 px карточка
  занимает почти весь экран, от 900 px — колонка справа на 36% ширины, карта
  остаётся слева и вписывается в свободную часть. В панели все факты раскрыты сразу.
  Выбор запоминается на устройстве
- **«Степной след»** — казахстанско-японский слой: 290 фактов на 51 точке,
  из них 33 в игровом формате (верю/не верю, что было раньше, угадай, задание
  на месте). Каждый факт помечен уровнем достоверности: ✅ факт · 🔗 параллель ·
  😄 шутка · ⚠️ предупреждение по маршруту — шутка не может прочитаться как история.
  Блок строится в момент открытия карточки, первые два факта видны сразу,
  остальные по кнопке. Источник данных — `kz_facts.json`
- **Задания** — 20 из игровых пунктов это задания «найди на месте». Они отмечаются
  галочкой в карточке или в списке в панели «Инфо», счётчик наверху списка.
  Отметки хранятся в localStorage **на устройстве каждого**: аккаунтов и синхронизации
  нет, у всех четверых свой прогресс. Все обращения к хранилищу в try/catch; если
  браузер его запрещает (приватный режим Safari), список честно об этом пишет,
  а галочки продолжают работать до перезагрузки. Id задания — хеш от названия точки
  и текста задания, поэтому пересборка и перестановка фактов отметки не сбрасывают

Если сеть есть, страница подтягивает тайлы OpenStreetMap и живой прогноз
Open-Meteo. Если нет — всё работает на вшитых данных.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `root` → Save.
Через минуту страница доступна по адресу выше.

> ⚠️ Pages на бесплатном тарифе делает страницу публичной. Здесь лежат точные
> даты поездки, районы отелей и рейсы — то есть период, когда дома никого нет.
> Если это смущает, держите репозиторий приватным и открывайте `index.html`
> локально, либо возьмите неочевидное имя репозитория.

## Пересборка

```bash
cd src
npm install                 # leaflet + leaflet.markercluster + world-atlas
node make_basemap.js        # -> japan_basemap.json
python3 build_guide.py      # -> Japan_Guide_2026.html
```

`build_guide.py` читает `stops.json`, `kz_facts.json`, `japan_basemap.json`,
`wx_baked.json` и `img/*.webp`, инлайнит библиотеки и картинки и пишет готовую
страницу. Скопируйте результат в `index.html` в корне.

Сборщик ожидает библиотеки в `src/package/dist/`: `leaflet.js`, `leaflet.css`,
`leaflet.markercluster.js`, `MarkerCluster.css`. Это раскладка npm-тарболов:

```bash
cd src
npm pack leaflet@1.9.4 leaflet.markercluster@1.5.3
tar xf leaflet-1.9.4.tgz && tar xf leaflet.markercluster-1.5.3.tgz
```

Каталог `package/` в git не хранится.

### Картинки

`img/*.webp` пересобираются из исходных PNG одной командой — генерация при этом
не запускается и кредиты не тратятся:

```bash
cd src
./make_images.sh              # 768px q75 — ровно под карточку на 3x-экране
SIZE=1024 Q=80 ./make_images.sh
```

Скрипт берёт список и ссылки из `img_prompts.json`, кэширует скачанные PNG
в `.img_cache/` (в git не хранится) и кладёт результат в `img/`.

### Правка контента

Маршрут правится в `stops.json`, фактический слой — в `kz_facts.json`.
Ключи `kz_facts.json` совпадают с полем `name` из `stops.json`; сборка падает
с ошибкой, если в фактах есть ключ, которому не соответствует ни одна точка.
Ручной правки разметки не требуется ни в одном случае.

## Тесты

Playwright, headless Chromium:

```bash
cd src/tests
python3 test_offline.py   # вся внешняя сеть заблокирована — карта, картинки, погода
python3 test_cluster.py   # кластеризация, разбор по зуму, фильтры
python3 test_overlap.py   # пересечения блоков на 9 разрешениях × 4 состояния панелей
python3 test_v3.py        # погода: forecast / climate / offline; панель бронирований
python3 test_kz.py        # «Степной след»: офлайн, сборка по тапу, раскрытие, ответы,
                          # отметки заданий, и замер времени до интерактивности
```

`test_kz.py` отдельно меряет время до интерактивности офлайн при ×4 замедлении CPU:
на текущей сборке ~255 мс против требования 2 с. Картинки в base64 остаются строками,
пока карточка не открыта, поэтому размер файла на старт почти не влияет.

Тесты ожидают `Japan_Guide_2026.html` рядом с собой.
