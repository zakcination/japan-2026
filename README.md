# Japan — 17–27 October 2026

Интерактивный гид по поездке: карта, маршрут по дням, погода, бронирования
и Ghibli-иллюстрации мест. Одна самодостаточная HTML-страница.

**Живая версия:** https://<username>.github.io/<repo>/

## Что внутри

`index.html` — 575 КБ, один файл, никаких внешних запросов:

- **Leaflet 1.9.4 + Leaflet.markercluster 1.5.3** — вшиты в страницу, не с CDN
- **Векторная карта Японии** — упрощённый TopoJSON (world-atlas), рисуется без тайлов
- **Названия городов** — 24 подписи, появляются по зуму
- **51 точка / 68 посещений** — кластеризация на общем плане, разбор при зуме,
  spiderfy для точек с одинаковыми координатами
- **17 иллюстраций** — `data:image/webp;base64` прямо в HTML
- **Погода** — климатические нормы на 17–27 окт для 5 городов зашиты в файл
- **Бронирования** — 13 позиций с датами, когда открывается запись
- **Google Maps** — ссылки на место и на маршрут (transit) из каждого попапа

Если сеть есть, страница подтягивает тайлы OpenStreetMap и живой прогноз
Open-Meteo. Если нет — всё работает на вшитых данных.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `root` → Save.
Через минуту страница доступна по адресу выше.

> ⚠️ Pages на бесплатном тарифе делает страницу публичной. Здесь лежат точные
> даты поездки, районы отелей и рейсы — то есть период, когда дома никого нет.
> Если это смущает, держите репозиторий приватным и открывайте `index.html`
> локально, либо возьмите неочевидное имя репозитория.

## Пересборка

```bash
cd src
npm install                 # leaflet + leaflet.markercluster + world-atlas
node make_basemap.js        # -> japan_basemap.json
python3 build_guide.py      # -> Japan_Guide_2026.html
```

`build_guide.py` читает `stops.json`, `japan_basemap.json`, `wx_baked.json`
и `img/*.webp`, инлайнит библиотеки и картинки и пишет готовую страницу.
Скопируйте результат в `index.html` в корне.

## Тесты

Playwright, headless Chromium:

```bash
cd src/tests
python3 test_offline.py   # вся внешняя сеть заблокирована — карта, картинки, погода
python3 test_cluster.py   # кластеризация, разбор по зуму, фильтры
python3 test_overlap.py   # пересечения блоков на 9 разрешениях × 4 состояния панелей
python3 test_v3.py        # погода: forecast / climate / offline; панель бронирований
```

Тесты ожидают `Japan_Guide_2026.html` рядом с собой.
