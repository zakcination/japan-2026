# Ассистент в приложении: как включить

Ассистент — это чат внутри приложения (круглая кнопка со звёздочкой справа внизу, над вкладками). Он виден только участникам группы, которые вошли со своим PIN. Отвечает модель Claude Opus 5.5 (`claude-opus-5-5`).

Что он умеет:
- подсказать, как пользоваться приложением;
- рассказать про день, найти место, перестроить план (дождь, закрыто, устали, опаздываем);
- переводить: фразы, фото меню и вывесок, голосовой переводчик с озвучкой по-японски;
- пересчитывать ¥ / ₸ / $ по курсам из «Деньги → Бюджет и курсы»;
- подсказать при беде: страховка Forte Travel, номера экстренных служб, посольство;
- рассказать про возможности карты Forte Travel.

Сам ассистент ничего не меняет. Перенос, «Без меня», новый пункт или расход появляются карточкой, и меняется что-то только после «Применить». Если гость меняет план группы, «Применить» отправляет предложение хозяевам. Расход открывается в обычном окне расхода, и сохраняете его вы.

Ключ Anthropic хранится только в секретах Supabase. В странице и в репозитории его нет. Номера карт, полисов и коды нигде не сохраняются.

## 1. Ключ Anthropic

1. Зайдите на https://console.anthropic.com и войдите (или зарегистрируйтесь).
2. Settings → Billing: пополните баланс по факту использования (pay as you go), например на $20.
3. Settings → Limits: поставьте месячный лимит расходов, например **$100**. Больше этой суммы не спишут, даже если что-то пойдёт не так.
4. Settings → API Keys → Create Key, назовите его `japan-assistant` и скопируйте ключ (он начинается с `sk-ant-…`). Ключ показывают один раз.

## 2. Секрет в Supabase

Supabase → проект `ajpiptdkybhtkaoozqet` → Edge Functions → Secrets → Add new secret:
- Name: `ANTHROPIC_API_KEY`
- Value: ключ из шага 1

`SUPABASE_URL` и `SUPABASE_ANON_KEY` Supabase добавляет сам, их трогать не нужно.

## 3. Функция `assistant`

1. Edge Functions → Deploy a new function → Via Editor. Имя функции: **`assistant`**.
2. Сотрите пример и вставьте целиком файл `supabase/functions/assistant/one_file.ts` из репозитория. Это один файл, в который уже встроены `logic.mjs` и `kb.mjs`.
3. В настройках функции оставьте **Verify JWT включённым** (так по умолчанию). Функция пускает только участников: она проверяет вызывающего тем же `group_state`, что и приложение, с его собственным входом. Service role для чтения данных не используется.
4. Deploy.

Если поменяли `index.ts`, `logic.mjs` или `kb.mjs`, пересоберите файл командой `python3 supabase/functions/bundle.py assistant` и задеплойте заново. Тест `test_assistant_logic.py` упадёт, если `one_file.ts` устарел.

## 4. Проверка

1. Откройте приложение на телефоне и войдите в группу.
2. Нажмите кнопку со звёздочкой. В первый раз ассистент спросит профиль: имя, язык (RU/KZ/EN), тон, энергию, интересы и ограничения в еде. Профиль хранится только на этом телефоне.
3. Спросите «Что у меня сегодня?». Ответ приходит за 5–20 секунд.
4. Если пишет «Ассистент ещё не настроен», значит нет секрета `ANTHROPIC_API_KEY`. Если «только для участников группы», войдите заново через ⚙. Ошибки видны в Supabase → Edge Functions → assistant → Logs.

## Сколько это стоит

Цены Claude Opus 5.5: $4 за миллион входных токенов, $20 за миллион выходных. Повторное чтение закешированной части (инструкции и справка) стоит $0.20 за миллион, запись в кеш — $5 за миллион. Поиск в интернете — $10 за 1 000 поисков.

| Что | Примерно за один раз |
|---|---|
| Обычный вопрос (план на сегодня, справка, как сказать) | $0.03–0.06 |
| Вопрос с поиском в интернете (часы работы, место) | $0.06–0.12 |
| Фото меню или вывески | +$0.01–0.02 |
| Фраза в голосовом переводчике | меньше $0.005 |

Ответы короткие («low» effort), за один вопрос не больше 8 шагов и 3 поисков, поэтому один вопрос не может стоить заметно дороже.

На всю поездку (5 человек, 11 дней):
- спокойно, по 10 вопросов на человека в день, около 550 вопросов: **≈ $25–40**;
- активно, по 20 вопросов в день и часто с фото: **≈ $60–90**.

Лимита в день нет. Месячный лимит $100 в консоли Anthropic — это страховка от сюрпризов.

## Сообщения по расписанию: утро, после мест, вечер (готово, но выключено)

Всё уже написано и проверено тестами, но включается только после того, как вы одобрите дизайн. Пока ассистент ничего не присылает сам, а в чате нет оценок.

Как это работает:
- **Утро.** Около 08:00 по местному времени дня (Япония UTC+9, шанхайские дни UTC+8) приходит одно сообщение: настрой, цель дня, совет по силам и ближайшие 2–3 пункта. Текст пишет Claude по профилю и плану дня. Ссылка ведёт в приложение (`#briefing`).
- **После места.** Когда закончилась прогулка, еда или событие из вашего плана, приходит push «Как вам …?», а в чате появляется карточка с пятью звёздами и строкой комментария (`#rate=<пункт>`).
- **Вечер.** Около 22:00 — «Как прошёл день?» и карточка оценки дня.
- **Ограничения.** Не больше 4 push в день; утро и вечер всегда помещаются. С 22:30 до 07:30 по местному времени push не приходят, сообщение остаётся только в приложении. Каждый тип можно выключить в профиле.
- **Приватность.** Оценки и комментарии видит только автор. Группе видно лишь среднее по месту, и только если оценили хотя бы двое. Номера карт и полисов нигде не хранятся.
- **Цена.** Около 2 коротких текстов в день на человека, то есть примерно 110 за поездку. Это меньше $2.

Как включить, когда одобрите:
1. Supabase → SQL Editor: выполните заново `supabase/migrations/001_group.sql`. Файл можно запускать повторно, он добавит таблицы `ai_profiles`, `ai_feedback`, `ai_sent` и функции к ним.
2. Пересоберите функцию **notify**: вставьте `supabase/functions/notify/one_file.ts` (она научилась доставлять сообщения ассистента). Verify JWT оставьте выключенным, как было.
3. Создайте ещё одну функцию **`assistant-cron`** и вставьте в неё тот же `supabase/functions/assistant/one_file.ts`, но **Verify JWT выключите**. Её вызывает база, а не телефон, и она проверяет себя секретом `HOOK_SECRET` (тот же, что у notify). Чат и в этой копии пускает только участников.
4. В приложении: в `src/today/ui/assistant.js` поменяйте `askP1` так, чтобы он возвращал `true`, и пересоберите сайт.
5. SQL Editor: `select cron.schedule('ai-messages', '*/10 * * * *', $c$select public._ai_tick()$c$);`
   Выключить обратно: `select cron.unschedule('ai-messages');`

## Если что-то не работает

- **Все запросы получают 401 ещё до функции** (в Logs пусто). Значит, шлюз Supabase не принимает токен входа при включённом Verify JWT. Выключить Verify JWT для `assistant` безопасно: функция сама пускает только участников группы через `group_state` с токеном человека.
- **Голосовой переводчик на iPhone.** В приложении с экрана «Домой» встроенное распознавание речи не работает, поэтому говорят через 🎤 на клавиатуре. Японский собеседник надиктует по-японски, только если на телефоне есть японская клавиатура: Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры → японская. Переключается она кнопкой 🌐.
