# Расходы в поездке — спецификация (06.10.2026)

Основа: ТЗ «Japan Travel Expense Tracker» (115 пунктов), адаптированное к нашему приложению. Решения владельца 06.10:
- свои расходы видит только сам человек (и его пара, если оба выбрали друг друга); группа видит только итоги по людям;
- «＋» по центру нижней панели: **Сейчас | День | ＋ | Дела | Деньги**; «Итоги» становится «Деньги»; карта — кнопкой на «День»;
- бюджет у каждого свой: пара (взаимный выбор «Считать вместе с») считает расходы и бюджет вместе.

## Что делаем до заморозки 15.10 (P0 + часть P1)
- Быстрое добавление: «＋» → сумма (цифровая клавиатура сразу) → категория → «Сохранить ¥1 500». Детали — под «Добавить детали»: дата, город, название/магазин, комментарий, способ оплаты, для переездов вид и «Откуда → Куда».
- Хранение: IndexedDB на телефоне — первая запись (< 100 мс, без сети); при входе в группу — очередь отправки в Supabase (`save_expense`), восстановление на другом телефоне из `group_state`. Клиентский UUID, повтор не создаёт дубль; «последняя запись побеждает» по `updatedAt`; удаление мягкое.
- Валюты: хранится сумма и валюта ввода, сумма в иенах (база) и курсы KZT/USD на момент расхода. Переключатель ¥ / ₸ / $ меняет только показ. Курсы — вручную в настройках (по умолчанию из настроек поездки).
- «Деньги»: потрачено / бюджет / осталось / % с полосой (зелёная < 70 %, жёлтая 70–90 %, красная > 90 %, «Бюджет превышен на …»); сегодня, вчера, средний за прошедшие дни, прогноз до конца; наличные осталось; по категориям; по городам (топ-5); история по дням с поиском и фильтрами (сегодня / вчера / 7 дней / вся поездка, категория, город, оплата); правка, дублирование, удаление с «Отменить»; группа — итоги по людям.
- Категории — 13 из ТЗ (коды те же). Город по умолчанию — город текущего дня поездки, без GPS.
- Экспорт CSV (колонки из п. 67), резервная копия JSON и её импорт с проверкой дублей.

## Позже (после поездки или по запросу)

## Безопасность
Таблица `expenses` закрыта RLS; доступ только через функции: свои строки пишет только автор; читать — автор и взаимная пара; остальным — только суммы по людям.
