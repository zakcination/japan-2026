# «Сегодня» — редизайн в стиле Apple и общая поездка через GitHub

Дата: 29.09.2026 · Итерация 1 · Статус: на ревью

## 1. Цель

Экран «Сегодня» в гиде на GitHub Pages должен читаться на ходу: одной рукой, на ярком солнце,
за две секунды. Сейчас он работает, но выглядит как длинная системная страница. Итерация меняет
оболочку (внешний вид, навигацию, темы) и даёт двум путешественникам одну общую поездку,
которая лежит в репозитории и подтягивается на оба телефона.
Логика (пересчёт, «выйти до», сдвиг дат, импорт/экспорт, `#trip=`) не меняется.

**Готово, когда:**
- на iPhone (390×844) вкладка «Сейчас» помещается в один экран без прокрутки и отвечает на три вопроса:
  что сейчас, что дальше, через сколько выходить;
- любая кнопка не меньше 44×44 pt и достаётся большим пальцем (нижняя половина экрана);
- правка поездки в репозитории появляется на обоих телефонах при следующем открытии с сетью, а без сети всё работает с последней загруженной версией;
- все существующие тесты карты и новые тесты проходят, приложение открывается офлайн;
- шаблон по-прежнему открывается у всех по умолчанию, а наша поездка — по ссылке `?trip=miras-aikosh`.

## 2. Что входит и что нет

**Входит:** дизайн-система Apple (светлая и тёмная), капсула «живой активности», сегменты дней,
пять вкладок, лист деталей пункта, темы по закату, поездки как файлы в репозитории (`trips/`),
иконки/заставки/превью ссылки, разбиение `today.js` на модули, тесты, ревью, публикация.

**Не входит (следующие итерации):** английский интерфейс, геолокация, QR для передачи поездки,
push-уведомления, Live Activity / виджеты / Apple Wallet (нужно нативное приложение), редизайн карты
(только подгонка цветов).

## 3. Визуальная система

Утверждена на макете: https://claude.ai/artifact/MWYmf6By4yLFUFkeXQ9r1R (6 экранов).

**Шрифт.** Системный SF: `-apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`.
Цифры — SF Rounded: `ui-rounded, "SF Pro Rounded", -apple-system`, всегда `tabular-nums`.
Никаких вшитых шрифтов (приложение становится легче; на Android подставится системный).

**Токены** (CSS-переменные в `theme.css`, светлая по умолчанию, тёмная через `[data-theme="dark"]`):

| Токен | Светлая | Тёмная |
|---|---|---|
| `--bg` | #F2F2F7 | #000000 |
| `--card` | #FFFFFF | #1C1C1E |
| `--text` | #1C1C1E | #FFFFFF |
| `--sec` | #8E8E93 | #8E8E93 |
| `--sep` | #E5E5EA | #2C2C2E |
| `--inset` | #F2F2F7 | #2C2C2E |
| `--seg` | #D1D1D6 | #3A3A3C |
| `--tint` | #E4002B | #FF375F |
| `--alert` | #FFCC00 | #FFCC00 |

Статусы — точка + слово (различимы без цвета): FIXED «Куплено» (text), PLANNED «По плану» #34C759,
FLEX «Гибко» #FF9500, INPUT «Купить» / «Нужны данные» #FF3B30.
Кольца «Итогов»: поездка #FF375F, сегодня #34C759, бюджет #0A84FF.

**Размеры.** Крупный заголовок 34/700; время события 56 (Rounded); «выйти через» 44;
большое время ночью 72; текст ≥ 15; кнопки-капсулы 52–58 высотой; радиусы карточек 22–28;
лёгкая тень только в светлой теме.

**Компоненты:** капсула, сегменты (11 делений, текущий день заполняется по ходу дня),
крупный заголовок места + «Вс 18 · 2/11», карточка, кнопка-капсула (главная — чёрная/белая,
второстепенная — `--inset`), строка списка с кружком-галочкой, точка статуса, лист снизу,
нижняя панель из пяти вкладок (полупрозрачная, blur).

**Доступность:** контраст текста ≥ 4.5:1 в обеих темах; `prefers-reduced-motion` отключает
пульсацию капсулы и анимации листа; поддержка увеличенного системного шрифта (размеры в `rem`
от системного); у кнопок-иконок `aria-label`; вкладки — `role="tablist"`.

## 4. Экраны и поведение

**Шапка (все вкладки кроме «Итогов» и «Карты»):** капсула → сегменты → место + дата/день.

**Капсула** всегда про самое срочное событие дня (первое будущее FIXED или межгородской транспорт,
иначе следующий пункт): значок транспорта, время, обратный отсчёт до «выйти в».
Меньше 30 минут до выхода → капсула жёлтая. Время выхода прошло, событие ещё не началось →
капсула жёлтая с «Пора». Тап по капсуле открывает «Сейчас».

**Сейчас** (без прокрутки): карточка «Сейчас» с прогрессом → карточка «Дальше»
(время 56, маршрут, японские названия там, где известны, плашка «Выйти через», кнопки
«Маршрут» / «Билет» / «Карта»). В состоянии «Пора» карточка «Дальше» становится жёлтой
с кнопкой «Начать маршрут» и строкой «план пересчитан», если пересчёт был. В день переезда
под карточками — «Сегодня ещё» (что после прибытия).

**День:** полоса недели (тап и свайп влево/вправо меняют день), список пунктов.
Тап по строке → лист снизу с деталями и действиями: Карта, Маршрут, Билет, ✎, +15, +30, Пропустить
(как сейчас, те же правила для FIXED). Кружок слева — отметка «сделано».

**Брони:** брони дня сверху, ниже вся поездка; «Куплено/Купить», прикрепить и показать билет
(IndexedDB, офлайн). Билет открывается на весь экран с подсказкой «прибавьте яркость» (менять яркость веб-приложение не может).

**Итоги:** три кольца (поездка, сегодня, бюджет), бюджет по дням столбиками,
плитки: пешком (план/факт, факт вводится), транспорт, потрачено (¥ + валюта дома), закат и погода.

**Карта:** существующая карта гида, открывается на выбранном дне.

**⚙ Моя поездка:** как сейчас (название, люди, дата, валюта, импорт/экспорт, шаблон) +
тема (авто по закату / светлая / тёмная) + синхронизация (раздел 5).

**Темы.** По умолчанию: светлая от рассвета до заката, тёмная после; закат считается локально
для города дня (уже есть `sunTimes`). Ручной выбор в ⚙ перекрывает авто.

## 5. Общая поездка через репозиторий

**Решение владельца:** наша поездка хранится в этом же публичном репозитории. Имена, рейсы,
название первого отеля и купленные брони будут видны любому, кто откроет репозиторий.
Номера билетов, места, телефоны, адреса и данные карт по-прежнему не публикуются никогда;
билеты (QR) живут только на телефонах.

**Файлы:**
- `trips/template.json` — шаблон «Япония за 11 дней» (бывший `src/today.json`);
- `trips/miras-aikosh.json` — наша поездка (из `today_data.py` + личных значений);
- `trips/index.json` — список поездок `[{id, name}]`.
`survey/private_overrides.json`, `trip_miras_aikosh.json` и сборка `PERSONAL=1` удаляются:
личные значения переходят в `today_data.py` открыто.

**Выбор поездки:** `?trip=<id>` в ссылке (запоминается на устройстве); без параметра — шаблон.
В ⚙ — переключатель поездки из `trips/index.json`.

**Загрузка:** шаблон и `trips/index.json` вшиты в `index.html` (открываются без сети с первого раза).
Выбранная поездка при открытии с сетью берётся из `trips/<id>.json` (тот же сайт, network-first,
service worker кэширует её для офлайна); без сети — последняя сохранённая. В шапке «⚙»
показывается «версия поездки от ДД.ММ HH:MM».

**Как правится общая поездка:** в репозитории — через claude.ai/code или GitHub. После push
телефоны получают её при следующем открытии с сетью. Кнопки ✎ в приложении делают **локальную**
копию на этом телефоне: приложение показывает «у вас свои правки — общая версия не подтягивается»
и кнопку «Вернуться к общей версии». Экспорт JSON из ⚙ позволяет отдать локальные правки,
чтобы внести их в репозиторий.

**Отметки** (✓, пропуски, задержки, траты) — у каждого телефона свои, в `localStorage`.

**`#trip=` и импорт/экспорт** остаются как есть.

**Безопасность:**
- `<meta http-equiv="Content-Security-Policy">`: `script-src 'self' 'unsafe-inline'` (скрипты только из самого файла),
  `connect-src 'self' https://*.open-meteo.com`; картинки (тайлы карты) не ограничиваются;
- поездка из файла или ссылки проверяется по схеме и выводится только через экранирование, ссылки только `https:`.

## 6. Структура кода

`src/today.js` (707 строк) разбивается, сборка по-прежнему склеивает всё в один `index.html`:

| Файл | Отвечает за | Зависит от |
|---|---|---|
| `src/today/core.js` | время Японии, даты, `plan()` (пересчёт), «выйти до», деньги, закат | — |
| `src/today/store.js` | поездка/настройки/отметки на устройстве, IndexedDB билетов, `#trip=` | core |
| `src/today/trips.js` | выбор поездки, загрузка `trips/<id>.json`, локальные правки поверх общей версии | store |
| `src/today/ui/shell.js` | шапка, капсула, сегменты, вкладки, темы, лист | core, store |
| `src/today/ui/now.js`, `day.js`, `bookings.js`, `stats.js`, `settings.js` | вкладки и ⚙ | shell |
| `src/today/theme.css`, `components.css` | токены и компоненты | — |

`core.js` без DOM — тестируется отдельно.

## 7. Ассеты

Через навык web-asset-generator (Pillow в отдельном venv): иконки приложения 180/192/512,
favicon, `apple-touch-icon`, заставки iOS (светлая), картинка превью ссылки 1200×630 для

## 8. Тесты

Навык webapp-testing (Playwright, Python):
- `core`: `plan()` — FIXED не двигается; задержка сокращает FLEX, потом PLANNED, только будущее;
  конфликт показывается; сдвиг даты и 📅-события; деньги × люди;
- экраны на 390×844 и 430×932: «Сейчас» без прокрутки, кнопки ≥ 44 pt, обе темы, «Пора»;
- поездки: `?trip=` загружает файл, без сети берётся сохранённая, локальная правка отключает обновление, «Вернуться к общей версии»;
- офлайн через service worker; все старые тесты карты (`#map`).

## 9. Порядок и выпуск

1. Навыки webapp-testing и web-asset-generator (прочитаны, безопасны).
2. Разбиение `today.js` без изменения поведения + тесты `core` (страховка).
3. Тема и компоненты → шапка/капсула → вкладки по одной → лист.
4. `trips/` и выбор поездки; перенос личных значений в `today_data.py` и `trips/miras-aikosh.json`.
5. Ассеты.
6. security-review, code-review → push → проверка GitHub Pages → ссылка `?trip=miras-aikosh` на оба телефона.

## 10. Риски

- **Личные данные публичны** (решение владельца): имена, рейсы, первый отель, купленные брони.
  Номера билетов, места, адреса, телефоны не публикуются.
- **Локальная правка «замораживает» поездку на телефоне** — видно по плашке, снимается одной кнопкой.
- **Обновление приходит только при открытии с сетью** — перед выходом стоит открыть приложение в отеле с Wi-Fi.
- **SF Rounded не на iPhone** — подставится системный шрифт, вёрстка не ломается.
